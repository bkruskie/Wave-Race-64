# Badge Generator for Wave Race 64

This directory contains auto-generated badge data for your GitHub repository.

## How It Works

1. **`tools/update_badges.py`** reads your `build/progress.json` (generated by your CI workflow)
2. **`github/workflows/badges.yaml`** runs on every push to `master`
3. Badge files are auto-generated and committed to this directory
4. Add the badge markdown to your repository's `README.md`

## Adding Badges to Your README

Copy and paste these lines into your repository's `README.md`:

```markdown
![Progress](https://img.shields.io/badge/progress-65.13%25-brightgreen)
![Functions](https://img.shields.io/badge/functions-889/1365-brightgreen)
```

The percentages and counts will auto-update on every push to `master`.

## Regenerating Badges Locally

If you want to regenerate badges manually:

```bash
python3 tools/update_badges.py
```

Then commit the `badges/` directory changes.

## Directory Structure

```
badges/
├── progress.json    # Raw badge data (JSON format)
└── badges.txt       # Shield.io badge URLs (copy to README)
```

## Notes

- The `badges/` directory is gitignored in `.gitignore`, but the workflow commits updates to it
- Badge counts reflect your current progress: **889/1365 (65.13%)** function conversions
- Run `python3 tools/update_badges.py` locally to regenerate before pushing
- The GitHub Actions workflow auto-updates badges on every push to `master`
